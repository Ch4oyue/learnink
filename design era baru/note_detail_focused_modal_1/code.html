Understanding State Management in React

tag React
JavaScript
Hooks

State is a built-in React object that is used to contain data or information about the component. A component's state can change over time; whenever it changes, the component re-renders. This is the core mechanism that makes React apps interactive.

# Using the useState Hook

The most common way to handle state in functional components is via the useState hook. It returns a stateful value, and a function to update it.

CounterComponent.jsx
import React, { useState } from 'react';

function Counter() {
  // Declare a new state variable, which we'll call "count"
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}

Notice how we destructure the array returned by useState. The first element is the current state, and the second is the setter function.

lightbulb

Async Nature

Remember: State updates in React may be asynchronous. React creates a queue of changes and batches them for performance. If you need the previous state value to calculate the next one, always pass a function to the setter: setCount(prev => prev + 1).

# When to use Redux or Context?

For simple component-level data, standard state is sufficient. However, when you have "prop drilling" (passing data down through many layers), you might consider the Context API.
