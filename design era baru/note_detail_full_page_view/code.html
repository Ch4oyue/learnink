Python Dictionary Methods

calendar_today Oct 24, 2023 schedule 5 min read

Dictionaries are Python's implementation of a data structure that is more generally known as an associative array. A dictionary consists of a collection of key-value pairs. Each key-value pair maps the key to its associated value.

Unlike sequences, which are indexed by a range of numbers, dictionaries are indexed by keys, which can be any immutable type; strings and numbers can always be keys.

lightbulb

Key Mutability

Tuples can be used as keys if they contain only strings, numbers, or tuples; if a tuple contains any mutable object either directly or indirectly, it cannot be used as a key.

The .get() Method

One of the most useful methods is .get(). It returns the value for the specified key if the key is in the dictionary.

example.py 
my_dict = {
    "brand": "Ford",
    "model": "Mustang",
    "year": 1964
}

# Safe retrieval
x = my_dict.get("model")

# With default value if key missing
y = my_dict.get("price", 15000)

Using .get() is safer than square bracket notation because it returns None (or a default value) instead of raising a KeyError when the key doesn't exist.
